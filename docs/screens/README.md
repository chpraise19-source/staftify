# Actual Next.js screen captures

These PNG files were captured with Chromium from the running `/development/facility`, `/development/nurse` and `/development/admin` routes. They show the real shared application components in clearly labeled, opt-in development review mode. They are screenshots, not standalone HTML applications or proof of live database writes.

The interactive review runs in Next.js. Navigation, search/filtering, schedules, dialogs, form validation and sample export can be reviewed; mutations display their live-access requirement. Production Supabase routes and security checks remain separate and protected.
